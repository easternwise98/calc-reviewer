# Calc Reviewer

**구조계산서를 설계기준과 대조해 검토해 주는 프로그램입니다.**

엑셀 계산서를 올려놓고 몇 분 기다리면, 어느 시트 어느 셀이 어떤 KDS/KCS 조항에
어긋나는지 근거와 함께 정리된 검토의견서가 나옵니다.

---

## 이걸 쓰면 뭐가 좋은가

**하나. 기준을 뒤지는 시간이 사라집니다.**
"이 항목이 몇 번 조항이더라" 하고 국가건설기준 사이트를 뒤지는 일을 프로그램이 합니다.
계산서 내용에 맞는 조항을 찾아서 원문까지 옆에 띄워 줍니다.

**둘. 근거 없는 지적을 하지 않습니다.**
모든 판정에 **계산서의 어느 행**과 **기준의 어느 조항**이 나란히 붙습니다.
클릭하면 계산서 해당 셀로 바로 이동합니다. 확인할 수 없는 건 "확인 못 했음"이라고
정직하게 적지, 그럴듯하게 지어내지 않습니다.

**셋. 사람이 잘 놓치는 걸 잡습니다.**
실제로 잡아낸 것들입니다.

- 사용철근량은 `S25-CTC125`인데 면적 산정은 `S22-CTC250`으로 되어 있는 표기 불일치 — 한 문서에서 8건
- 활동 안전율이 수동토압을 포함했을 때 2.0에 미달
- 온도철근 필요철근량 산정식에 항이 빠짐
- 노출등급 표의 최소 피복두께·기준압축강도 대조

**넷. 계산서가 밖으로 나가지 않습니다.**
검토는 전부 본인 PC에서 돕니다. 회사 서버도, 클라우드 업로드도 없습니다.
설계기준 조항을 불러올 때만 국가건설기준센터에 요청합니다.

**다섯. 추가 요금이 없습니다.**
본인이 이미 쓰는 ChatGPT 또는 Claude 구독을 그대로 씁니다. 별도 결제가 없습니다.

**여섯. 검토 노하우를 쌓고 나눌 수 있습니다.**
설계기준외 관행법 같은 본인만의 판단 기준을 등록해 두면
다음 검토부터 그 관점의 의견이 붙습니다. 파일로 저장해서 동료에게 그대로 넘길 수도 있습니다.
(이 지식은 **의견에만** 반영되고 판정 자체는 건드리지 않습니다 — 그래서 남의 지식을
받아 써도 안전합니다.)

---

## 어떻게 쓰나

1. **엑셀 계산서를 올립니다.** 시트 목록과 구조물 종류가 자동으로 잡힙니다.
2. **검토할 시트를 고르고 실행합니다.** 진행 상황은 작은 별도 창에 뜹니다.
   그동안 다른 일을 해도 됩니다.
3. **결과를 봅니다.** 부적합·보완 요청이 위로 올라옵니다.
   항목을 열면 계산서 근거와 기준 조항이 좌우로 나란히 보입니다.
4. **판단을 남깁니다.** 항목마다 수용 / 거부 / 보류와 메모를 기록합니다.
5. **보고서를 받습니다.** 제출용 검토의견서를 그대로 저장하거나 인쇄합니다.

검토 시간은 문서 크기에 따라 **3분(작은 계산서) ~ 30분(20시트 규모)** 정도입니다.

궁금한 게 있으면 화면 아래 **챗봇**에게 물어보면 됩니다.
"왜 이런 판정이 나왔나", "보완 요청 문구 초안 좀" 같은 걸 열려 있는 검토 결과를 근거로 답합니다.

## 지원하는 것

- **파일**: 엑셀 계산서(`.xlsx`, `.xlsm`), 텍스트 PDF
  (스캔본 PDF는 글자를 읽을 수 없어 거절합니다)
- **기준**: KDS / KCS 국가건설기준 전체
- **구조물**: 옹벽, 암거, 교각/교대, 거더, 접속슬래브, 난간벽, 터널 라이닝, 말뚝기초 등
  (자동으로 감지하고, 틀리면 직접 고를 수 있습니다)
- **외국 기준 계산서**: AASHTO·ACI·Eurocode를 인용한 영문 계산서도 됩니다.
  자동으로 번역한 뒤 국내 대응 기준으로 검토하고, 보고서는 한국어 계산서와 똑같은 판형으로 나옵니다.

## 설치

[릴리스 페이지](https://github.com/easternwise98/calc-reviewer/releases/latest)에서
설치 파일(약 146MB)을 받아 실행하면 끝입니다. 파이썬 같은 걸 따로 깔 필요 없습니다.

처음 한 번만 두 가지를 준비하면 됩니다.

1. **AI CLI 로그인** — 메뉴 `도움말 → AI CLI 설치`에서 Codex(ChatGPT) 또는 Claude 중
   쓰는 쪽을 설치하고 한 번 로그인합니다.
2. **KCSC API 키** — 메뉴 `도움말 → KCSC API 키 발급`에서 무료로 받아
   `설정 → API` 탭에 붙여넣습니다.

자세한 순서는 [설치 안내](calc-reviewer-engine/docs/설치안내.md)를 보세요.

업데이트는 프로그램을 켤 때 자동으로 확인하고, 헤더의 배지를 누르면 몇 초 만에 끝납니다.
(다시 설치할 필요 없습니다.)

---

## 먼저 둘러보기

설치하고 나면 `도움말 → 예시 검토 결과 열기`로 이미 끝난 검토 한 건을 볼 수 있습니다.
이어서 `도움말 → 사용법 안내 시작`을 누르면 8단계로 화면을 짚어 줍니다.

## 알아둘 것

- **최종 판단은 사람이 합니다.** 이 프로그램은 검토를 대신하는 게 아니라,
  확인할 것을 빠짐없이 찾아내고 근거를 나란히 놓아 주는 도구입니다.
- 설계기준의 일부 수식은 원문이 이미지로 제공되어 정확히 읽지 못하는 경우가 있습니다.
  그런 항목은 확정 판정 대신 "확인 필요"로 표시하고 사유를 적습니다.
- 처음 실행할 때 Windows가 파란 경고 창을 띄울 수 있습니다
  (코드 서명 인증서를 붙이지 않아서입니다). `추가 정보 → 실행`을 누르면 됩니다.
